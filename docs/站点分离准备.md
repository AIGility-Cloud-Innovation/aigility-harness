## 三、包分发策略（workspace:* 的三个去向）

| 路线 | 做法 | 优劣 |
|---|---|---|
| **A. npm 私服发布**（推荐终态） | 各包补 build（tsc/tsup）+ version + `publishConfig`；站点改 semver 引用 | 正规、可版本化；前置：每包 README/测试/exports 齐备（role-kit/workflow-studio 已达标） |
| **B. git 依赖** | `"@aigility-harness/role-kit": "git+ssh://…#v0.1.0"` | 免私服；安装慢、无范围语义 |
| **C. 同机 file: 引用**（推荐过渡） | 站点仓留最小 `pnpm-workspace.yaml` 指向 `../aigility-harness/packages/*` | 零改造立即工作；要求同机部署 |

**推荐路径：C（过渡，改动≈0）→ A（终态）。** 当前所有包 `main/exports` 直指 TS 源码，
路线 C 下站点构建（vite/tsx）可直接消费；走 A 时再补构建产物。

`FEISHU_USER_TOKEN_STORE`
