# aigility-harness · AppBase 启动指南（本机）

> 目标：启动 AppBase 并访问应用大厅 <http://127.0.0.1:3419/hall>
> 适用环境：本机（Windows 10，便携版 Node/Git，数据目录 `D:\DATABASE`）

## 一键启动（推荐）

双击运行：

```
D:\SiteWorkspace\aigility-harness\examples\appbase\start-appbase.cmd
```

脚本会自动：检测并启动 PostgreSQL → 设置环境变量 → 启动 AppBase。

## 手动启动（分步）

### 0. 前置条件（本机已就绪，仅换电脑时需要重装）

| 组件 | 位置 / 说明 |
|---|---|
| Node.js ≥20 | 便携版 `D:\SiteWorkspace\tools\node-v24.19.0-win-x64`（不在 PATH，需手动加入） |
| pnpm ≥9 | 9.15.9（装在上述 Node 里） |
| Git | 便携版 `D:\SiteWorkspace\tools\PortableGit\cmd`（私有依赖需要，凭据已存 GCM） |
| PostgreSQL 15 | 程序 `C:\Program Files\PostgreSQL\15`，数据目录 `D:\DATABASE`，端口 5432 |
| 依赖 | 仓库根目录已执行 `pnpm install`（210 包） |

### 1. 启动 PostgreSQL

服务端程序没有注册为 Windows 服务，需用 pg_ctl 手动启动：

```bat
set PATH=D:\SiteWorkspace\tools\PortableGit\cmd;%PATH%
"C:\Program Files\PostgreSQL\15\bin\pg_ctl.exe" -D "D:\DATABASE" -l "D:\DATABASE\log\manual-start.log" start
```

数据库信息：

| 项 | 值 |
|---|---|
| 主机 / 端口 | 127.0.0.1 / 5432 |
| 数据库 | `appbase` |
| 用户 / 密码 | `postgres` / `AppBase2026pg` |

### 2. 启动 AppBase

```bat
set PATH=D:\SiteWorkspace\tools\node-v24.19.0-win-x64;D:\SiteWorkspace\tools\PortableGit\cmd;%PATH%
cd /d D:\SiteWorkspace\aigility-harness\examples\appbase
set AGENT_DRIVER=zcode
set APPBASE_PG_HOST=127.0.0.1
set APPBASE_PG_PORT=5432
set APPBASE_PG_DATABASE=appbase
set APPBASE_PG_USER=postgres
set APPBASE_PG_PASSWORD=AppBase2026pg
rem set BIGMODEL_API_KEY=你的智谱Key   （配置后对话/生成功能可用）
pnpm start
```

看到 `AppBase 已就绪: http://127.0.0.1:3419/hall` 即启动成功。

## 启动后访问

| 服务 | 地址 |
|---|---|
| 应用大厅（hall） | <http://127.0.0.1:3419/hall> |
| 班主任小本本等应用 | <http://127.0.0.1:3419/apps/应用名.html> |
| 后端 API | <http://127.0.0.1:3419/app/apps> |
| AI 网关（需 Bearer 鉴权） | <http://127.0.0.1:3418/v1/chat/completions> |

## 注意事项

- **关机后重启**：PG 和 AppBase 都不会自启，重新运行一键脚本即可。
- **BIGMODEL_API_KEY 未配置**：页面能打开，但对话/网页生成/AI 结构化不可用。AI 网关密钥若未用 `APPBASE_GATEWAY_KEY` 指定，每次启动会随机生成并打印在控制台。
- **首次装依赖**：需 git 凭据拉取私有包 `@timem/dsh-plugin-timem`（git.aigility.cloud），GCM 会弹浏览器登录 Gitea 账号。
- **局域网访问**：服务监听 `0.0.0.0`，本机局域网 IP 为 `192.168.1.10`，其他设备可访问 `http://192.168.1.10:3419/hall`（需在 Windows 防火墙放行 3419/3418 入站）。
